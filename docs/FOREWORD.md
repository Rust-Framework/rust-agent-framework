# 前言

## 为什么写这本书

2024 年，Microsoft 发布了 Agent Framework (MAF)，为 AI 智能体开发提供了完整的工程化范式。然而 MAF 基于 C# / Python 生态，对于追求极致性能、内存安全和并发效率的场景，Rust 是更优选择。

Rust Agent Framework (RAF) 正是在这样的背景下诞生的。它严格对标 MAF 的设计理念——工具调用循环的装饰器管道模式、人机协同审批链路、上下文提供器扩展体系、多智能体编排——同时充分发挥 Rust 在异步运行时、零成本抽象和内存安全方面的优势。

本书的目标是：**为 AI 智能体开发者提供一本完整的 RAF 技术参考**，让你能像查阅 MAF 官方文档一样，快速理解和掌握 RAF 的每一个设计细节。

## 本书适合谁

- **AI 智能体开发者**：正在或准备构建基于 LLM 的自主智能体系统
- **Rust 中级开发者**：已熟悉 Rust 基础，希望在 AI 领域应用 Rust
- **架构师**：需要深入理解框架设计理念，做出技术选型决策
- **MAF 用户**：希望将 MAF 经验迁移到 Rust 生态

## 本书结构

本书共 14 章，按"入门→核心→进阶→扩展"四阶段组织：

- **第 1 章**：快速入门，带你构建第一个 Agent
- **第 2-3 章**：理解架构分层和 Agent 引擎的运行原理
- **第 4-9 章**：深入工具系统、上下文管理、会话、审批、工作区和管道
- **第 10-14 章**：宏、多智能体编排、扩展生态、宿主服务和参考附录

## 约定与格式

- 代码块使用 ` ```rust ` 标记，附有来自 RAF 源码的真实示例
- 架构图使用 Mermaid 格式，可在支持的 Markdown 渲染器中直接展示
- 关键术语首次出现时使用 **粗体** 标记
- Rust trait 和类型使用 `反引号` 标记
- 每个小节末尾提供「下一步」导航
