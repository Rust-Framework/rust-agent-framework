# 记忆检索导航

本文件是 `skill-memory` 的记忆检索导航。需要回忆时按以下流程判断目标类型，再通过 `read_skill_resource("skill-memory", "<路径>")` 读取具体文件。

可用工具：
- `load_skill("skill-memory")` — 加载本导航文件
- `read_skill_resource("skill-memory", "<路径>")` — 读取具体记忆文件

**规则：所有路径均为预期结构模板。只读取你确定存在的文件。读取前不假设文件内容。**

---

## 一、检索决策

```
用户问题/对话场景
        │
        ▼
┌──────────────────────────────────┐
│ 属于哪类记忆？                    │
│                                  │
│ ● 自身相关（人格/偏好/用户/       │
│   经验教训/行事准则）             │
│   → 读 references/ 对应文件       │
│                                  │
│ ● 权威知识（专业资料/规范/文档）   │
│   → 进入 assets/ 结构            │
│                                  │
│ ● 两者都有 → 先查 references/    │
│               再查 assets/      │
└──────────────────────────────────┘
```

---

## 二、references/

| 路径 | 用途 |
|------|------|
| `references/SOUL.md` | 人格设定：角色定位、语言风格、行为倾向 |
| `references/PREFERENCE.md` | 偏好配置：用户设定的偏好（格式、方向等） |
| `references/USER.md` | 用户信息：姓名、身份、背景、场景 |
| `references/LESSON.md` | 经验教训：过往错误、用户纠正 |
| `references/RULES.md` | 行事准则：特定场景的固定处理规则 |

使用规则：
- **按需读取**：需要哪类读对应文件，不全部加载。
- **先读后答**：涉及上述类别时先读文件再回答，不猜测。
- **更新写入**：获取新信息后更新对应文件。
- **冲突处理**：以用户最新表达为准并更新文件。

## 三、assets/

### 目录模板

```
assets/
├── INDEX.md                        ← 总目录（列出所有主题）
└── {主题目录}/
    ├── INDEX.md                    ← 该主题的章节目录
    ├── {章节文件名}                ← 具体章节
    └── ...
```

`{主题目录}` = 主题英文或拼音名（如 `rust`、`csharp`、`law`）
`{章节文件名}` = 按实际写入的文件名读取

### 检索步骤

```
① 读 assets/INDEX.md
   了解现有主题
   → 若无相关主题，说明该资料尚未写入

② 有匹配主题时
   读 assets/{主题}/INDEX.md
   浏览该主题的章节列表

③ 找到目标章节后
   读 assets/{主题}/{章节文件名}
   获取具体内容

④ 始终渐进：先览目录，再读细节
```

### 规则

- **只读确定存在的文件**：读取前通过 INDEX.md 确认文件是否存在，不假设。
- **逐级定位**：`INDEX.md → 主题/INDEX.md → 主题/章节文件`，不跳级。
- **渐进披露**：先展示目录范围，按需深入，不一次性加载整体。
- **权威来源**：仅收录用户认定的权威资料，不做主观推导。

---

## 四、总则

1. **先读后答**：涉及已知信息时先读文件再回答。
2. **不假设**：不假设文件存在，不假设文件内容。
3. **区分记忆区**：`references/` 是自身记忆；`assets/` 是外部知识。
4. **用户优先**：用户最新表达优先于历史记录。

---

## 五、读写配对

读取与写入使用相同的目录结构：
- 主代理通过 `load_skill` / `read_skill_resource` **读取**记忆
- MemoryAgent 在后台**写入**和**维护**记忆
- 你不需要关心写入——MemoryAgent 会自动处理
- 你只需要在需要回忆时按本文件指引读取
