# rust-agent-cli

命令行入口，框架的示例与集成演示。

## 功能定位

将各 crate 组装为可运行的 CLI 程序，演示框架的完整使用流程，同时可作为实际项目的起点。

- 初始化日志与 tracing
- 组装 `IChatClient` → `ITool` → `IAgent` → `ISession` → `IWorkflow`
- 流式消费 agent 输出并打印到终端

## 专属职责

- 作为二进制入口点，串联所有 crate
- 演示框架的标准使用模式
- 提供最小可运行示例

## 不做什么

- 不定义任何 trait、接口或核心类型
- 不实现业务逻辑
- 不做 REPL 交互（可由外部项目扩展）
- 不是框架的必需组件（用户可自行编写入口替换）
